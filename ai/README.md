# 개인 사용 패턴 Colab 실험

현재 서비스 판정은 `domain/personal_model/engine.py`의 `PersonalUsageModel`을 사용합니다. [1인 가구 중년·노년층 가상 시나리오 노트북](밥심_1인가구_중노년_가상시나리오_Colab.ipynb)은 이 코드를 그대로 포함하므로 Google Colab에서 파일을 열고 **런타임 → 모두 실행**하면 별도 패키지·저장소 인증 없이 재현됩니다. 노트북의 실행 결과와 생성 코드는 `python -m ai.build_personal_usage_colab`으로 다시 만들 수 있습니다. 이전 [소규모 실험 노트북](밥심_개인사용패턴_학습_Colab.ipynb)은 비교용으로 보존합니다.

- `target_cohort_experiment.py`는 1인 가구 중년·노년층의 **가상** 생활 유형 8개를 균형 있게 생성합니다. 아침 결식 가능성, 하루 한 번 사용, 이틀 간격 조리, 주말 시간 변화 등을 시험하지만 유형별 비율과 밥솥 사용 확률은 문헌에서 측정된 값이 아닙니다.
- 가상 가구마다 초기 28일을 시간 순서대로 학습하고 뒤의 28일을 평가합니다. 훈련 32가구에서 기준 확률 후보를 선택하고, 별도 보류 32가구와 생활 패턴 변화 16가구에서 확인합니다. 가구별 시드는 겹치지 않습니다.
- 고정 24시간 미사용 기준과 내부 `check_required` 후보를 비교합니다. 시간대 및 간격 판정은 현재 모델 코드를 사용합니다. 외출·통신 단절은 활동 없음으로 세지 않습니다. 포착률과 오경보율 외에 28일당 가구별 불필요한 내부 후보 수도 표시합니다.
- 훈련 가구에서만 최대 1시간의 늦은 사용 유예와 간격 분위수(현재 95%, 실험 후보 75%)를 비교합니다. 보류·생활 변화 가구의 포착과 불필요한 후보를 모두 공개합니다. 실험 후보는 운영 기본값에 자동 적용되지 않습니다.
- [결과 JSON](target_cohort_result.json)은 **가상 상황의 기능·민감도 실험**입니다. 정상적인 밥솥 미사용과 시나리오상 사용 중단은 센서 관측만으로 구별되지 않을 수 있습니다. 실제 식사·건강 상태, 실제 생활 오경보율, 휴대폰 푸시 성능을 뜻하지 않습니다. 후보 값은 운영 설정에 자동 적용되지 않습니다.

## 다조건 가상 학습과 미공개 조건 검증

[다조건 노트북](밥심_다조건_가상학습_Colab.ipynb)은 `python -m ai.build_condition_matrix_colab`으로 재생성합니다. `condition_matrix_experiment.py`는 규칙적인 아침·저녁, 하루 두 번, 격일 사용 가구를 두고 안정적 사용·늦은 사용·자연스러운 건너뜀·3일 간격 조리를 훈련 조건으로 조합합니다. 점진적 시각 이동·주말 이동·건너뜀과 늦은 사용의 결합은 후보 선택에 쓰지 않는 별도 검증 조건입니다. 시드도 분리하며 가구마다 과거 21일을 학습한 뒤 미래 21일을 평가합니다.

[다조건 결과 JSON](condition_matrix_result.json)에는 현재 운영 설정과 훈련 조건으로만 선택한 실험 설정의 전체·조건별 누락 포착, 정상일 내부 후보, 가구당 21일 불필요한 후보가 있습니다. 이 분리는 가상 생성기 내부의 과적합을 찾기 위한 것으로 실제 생활 성능을 입증하지 않습니다. 후보는 운영에 자동 적용되지 않으며, 실제 보호자 푸시 횟수가 아닌 모델 내부 후보를 셉니다.

기존 [가중치 실험 노트북](밥심_가중치_실험_Colab.ipynb)과 `calibration.py`는 이전 `RuleDetector` 비교용 기록입니다. 현재 개인화 모델의 학습 결과로 사용하지 않습니다.

## 실제 기록 평가를 위한 로컬 준비

[평가 기록 규약](../docs/개인화_평가_기록_규약.md)에 가명 관측·별도 확인 라벨의 JSONL 형식과 제외 기준을 적었습니다. `python -m ai.demo_usage_records --output-dir local-data/usage-demo`로 두 가상 가구의 관측·라벨·보고서를 만들고, `python -m ai.usage_record_pipeline --help`로 별도 기록 평가 명령을 확인할 수 있습니다. 이 경로는 로컬 오프라인 평가용이며 Colab 노트북이나 운영 알림 기준을 자동으로 바꾸지 않습니다.

보고서는 모델의 내부 후보(`personal`)와 상태 관리 규칙을 통과한 발송 요청(`notification_request`)을 따로 집계합니다. 가상 날짜별 라벨과 평가 시각은 실생활 확인 자료가 아니므로 보고서 수치를 실제 정확도로 읽지 않습니다.
