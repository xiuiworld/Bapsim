# Home Assistant 공유 설정 — A와 B

A는 연결·환경 예시, B는 대시보드·알림·확인/기간 보류 설정을 담당합니다. 구현할 때 파일별 담당과 적용 방법을 이 문서에 적습니다. 아직 실제 HA 설정 파일은 없습니다.

실사용 HA 설정 전체나 .storage/secrets.yaml은 복사하지 않습니다. 필요한 파일만 비밀 없는 템플릿으로 관리합니다. 자동 생성 엔티티 ID는 코드에 고정하지 않고 설치별 매핑으로 전달합니다.

실물 Matter 접점을 생활 패턴 학습에 연결하려면 같은 `device_id`에 **연결 확인용 주기 보고 엔티티**를 먼저 등록합니다. HA 서비스 `bapsim.register_matter_board_signal`에 실제 Matter 엔티티 ID, `kind: observation`, `signal: uptime`(숫자가 증가하는 값) 또는 `signal: snapshot`(보고마다 값이 변하는 확인 값)을 넣습니다. 그다음 `bapsim.register_matter_contact`로 접점 엔티티와 열림 극성을 등록합니다. 엔티티 ID는 실제 HA 수신 결과로 확인해야 하며, 현재 특정 보드 매핑이 실기 검증된 것은 아닙니다.

새 연결 보고가 확인되기 전에는 접점의 HA 캐시값만으로 온라인 판정하지 않습니다. 보고가 3분을 넘기거나 Uptime이 감소하면 관측 구간을 끊고, 다음 보고에서 현재 접점값을 새 기준 상태로 읽습니다. 이 3분은 [Matter·HA 명세](../docs/contracts/Matter_HA_연동_명세.md)의 60초 보고·3회 누락 시작값을 코드에 적용한 후보이며 실제 보고 주기와 단절·복구 시험 후 조정해야 합니다. 연결 보고 엔티티가 없다면 실물 사용 공백 알림은 보류됩니다. 시뮬레이터에는 이 Matter 연결 조건을 적용하지 않습니다.
