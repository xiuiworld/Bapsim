## 공개 자료 사전 점검

Git 추적 텍스트 파일 308개(`firmware/` 제외)에서 일반적인 개인 키·GitHub/OpenAI/Google API 키 패턴을 파일 내용 노출 없이 검사했고 일치 파일은 없었다. 이는 모든 비밀값 부재를 보증하지 않는다. Git 추적 파일 목록에는 `.env`, `local-data/`, `dist/`와 키 파일 확장자가 없었다. B의 직접 명시된 Python 외부 의존성은 `service/requirements.txt`의 `paho-mqtt==2.1.0`이다. 저장소 루트에 LICENSE/NOTICE 파일은 없으므로 공개 라이선스와 의존성 고지는 확정 전이다. 개인 기록·설치 설정·토큰과 생성 ZIP은 공개 묶음에서 제외하고, 실제 게시 전 최종 파일 목록을 다시 검사한다.

`paho-mqtt` 2.1.0의 [해당 버전 라이선스 파일](https://github.com/eclipse-paho/paho.mqtt.python/blob/v2.1.0/LICENSE.txt)은 EPL 2.0 또는 EDL 1.0의 이중 라이선스를 명시한다. 공개 묶음을 만들 때 해당 버전의 고지와 라이선스 전문을 포함할지 확인해야 한다. 밥심 자체의 공개 라이선스는 팀 합의가 아직 없다는 사용자 확인을 받았으므로 임의로 LICENSE 파일을 추가하지 않는다.

`python -m tools.build_b_source_candidate`로 B 코드·시험·재현 도구·계약/운영 문서만 담은 검토용 ZIP `dist/bapsim_b_source_candidate.zip`을 생성했다. 명시적 허용 목록의 소스 171개와 파일별 SHA-256 목록을 담고, `firmware/`, `.env`, `local-data/`, 배포 ZIP, 관련 없는 작업 트리 파일은 제외했다. ZIP 안의 `RELEASE_CANDIDATE_NOTICE.md`는 프로젝트 라이선스 미결정과 `paho-mqtt` 고지를 표시한다. 현재 산출물은 **검토용**이며 자체 라이선스 결정·최종 내용 확인 전에는 공개하지 않는다.
