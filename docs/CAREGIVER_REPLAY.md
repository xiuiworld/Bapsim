# 분리된 합성 사용 기록 재생

설정 → 연결 및 시험 도구 → 합성 기록으로 사용 흐름 보기에서 시작한다. 기본 제품 화면에서 별도의 시뮬레이션 출처와 시연 시각을 표시한다. 재생·정지, 1/2/4배속, 처음으로, 시연 종료를 제공한다.

`python -m tools.build_caregiver_replay`는 14일간 오전 8시·오후 7시 전후 ±9분의 개방과 2–4분 뒤 닫힘 기록을 만든다. 기존 AnalysisService가 개인 기준·공백·확인 요청을 계산하며 정책과 대기시간은 유지한다. 시작 화면은 학습된 9월 15일 오전 8:03 기록이며 요청에서 자동 정지한다.

보호자 응답은 기존 workflow가 미리 계산한 같은 사건의 결과로 이동한다. 재생의 설정은 브라우저 메모리에만 저장하며 이미 계산된 결과를 재분석하지 않는다. 운영 HA 서비스·실사용 기록·개인 기준에는 쓰지 않는다. 새 재생은 설정을 초기화하고 종료하면 실제 관측으로 돌아간다.

원시 합성 입력은 simulator 출처이며 임시 분석 상태에서만 처리한다. 취사·보온·온도는 만들어 채우지 않는다. 전달 함수는 로컬 대체 함수이며 실제 HA 호출이나 휴대폰 발송을 입증하지 않는다.

생성 결과는 `www/bapsim-caregiver-replay.json`이다. 새 JSON 반영 후 켜져 있던 재생은 종료하고 다시 시작한다. 검증은 `python -m unittest discover -s tests -p test_caregiver_replay.py`와 카드 JS 테스트로 수행한다.
