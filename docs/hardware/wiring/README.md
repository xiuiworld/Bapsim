# 밥심 센서 배선도

nRF54LM20-DK / PCA10184 rev 0.7.0의 광센서 4개·NTC 프로브·개폐 센서 연결 자료다. [센서 배선 사전설계](../A08_센서_배선_사전설계.md)와 함께 읽는다.

- `Bapsim_All_Sensors.fzz`: Fritzing에서 열고 편집할 전체 배선도. 사용자 정의 부품과 SVG를 파일 안에 포함하므로 임시 부품 폴더에 의존하지 않는다.
- `index.html`: 브라우저로 볼 수 있는 채널별 배선 안내.
- `overview.svg`, `ch0.svg`~`ch5.svg`: 전체 및 채널별 그림.
- `parts/`: 보드·브레드보드·센서·저항의 사용자 정의 부품 원본과 Fritzing 부품 묶음.
- `connections.json`: 채널·핀·브레드보드 위치 대응표.
- `validation.json`: 생성 시 연결 그래프의 정적 검사 결과. 실제 배선·전압·센서 정확도 검증은 아니다.

Fritzing 프로그램은 저장소에 포함하지 않는다. 프로그램을 별도로 준비한 뒤 `.fzz`를 열면 된다. 이 부품들은 브레드보드 연결을 표현하는 용도이며 PCB 제작용 풋프린트나 회로 시뮬레이션 모델은 제공하지 않는다.

원본 생성기는 저장소 루트의 `tools/build_sensor_wiring.py`다. `python tools/build_sensor_wiring.py`로 생성 자료를 다시 만들 수 있지만, 기존 파일을 덮어쓰므로 Fritzing에서 편집한 도면은 먼저 별도 사본으로 보관한다.

2026-10-07: 저장된 도면에 사용자 정의 부품이 빠지고 삭제된 임시 폴더 경로만 남은 문제를 수정했다. 기존 객체·배선 배치를 유지하며 부품 7개와 SVG를 다시 포함했다. XML·압축 무결성과 사용자 절대 경로 미포함을 확인했다. 수정본의 GUI 재열기 확인은 별도다.

프로그램 실행 파일·다운로드 압축본·설치 바로가기·개인 설정·실측 로그·이전 도면 백업은 Git에 포함하지 않는다.
