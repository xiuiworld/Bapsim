보고 연결하는 센서 배선도

먼저 전원 배선을 확인하고, 아래 버튼으로 센서를 하나씩 선택하세요. 색은 선을 구분하기 위한 표시이며, 같은 색의 실제 점퍼선이 없어도 라벨로 구분할 수 있습니다.

지금까지 확인한 것: 광센서 1채널이 가림 524–528 / 노출 4092로 변했습니다. 이 값은 밥솥 LED 임계값이 아닙니다. 밝은 쪽은 상한에 가까우며, 공급 전압·저항·전체 회로·실제 LED 판정은 아직 실측 검증 전입니다. 배선 변경 전 USB를 빼세요.

구멍별 연결표

현재 시험한 첫 광센서의 A10/A12, B12/B17, C12/C22, E22 위치를 기준으로 확장했습니다. 밥솥 부착 시 센서를 빼고, 센서의 두 선을 같은 두 구멍에 연결하세요.

이 그림은 사진 위쪽 번호 기준 0–62 참조 격자입니다. 아래쪽 거꾸로 인쇄된 번호를 섞어 읽지 마세요. 제품마다 시작 번호가 다르면 같은 이름의 구멍인지 먼저 대조해야 합니다. 그림의 선 길이는 실제 케이블 길이가 아닙니다.

센서센서의 두 선저항 다리전원 줄 연결보드 신호선
1. 잠금 표시A10 ↔ A12B12 ↔ B17 (10kΩ)
C12 ↔ C22 (10kΩ)		B10 → 빨강
C17 → 파랑		E22 → P1.03
2. 보온 표시A25 ↔ A27B27 ↔ B32 (10kΩ)
C27 ↔ C37 (10kΩ)		B25 → 빨강
C32 → 파랑		E37 → P1.04
3. 백미 표시J10 ↔ J12I12 ↔ I17 (10kΩ)
H12 ↔ H22 (10kΩ)		I10 → 빨강
H17 → 파랑		F22 → P1.05
4. 시간 첫 표시J25 ↔ J27I27 ↔ I32 (10kΩ)
H27 ↔ H37 (10kΩ)		I25 → 빨강
H32 → 파랑		F37 → P1.06
5. 외부 온도A48 ↔ A53B43 ↔ B48 (10kΩ)
C48 ↔ C58 (10kΩ)		A43 → 빨강
B53 → 파랑		E58 → P1.29
6. 뚜껑 개폐J48 ↔ J53I43 ↔ I48 (10kΩ)J43 → 빨강
I53 → 파랑		F48 → P1.10

전원 줄은 이렇게 연결

  1. 보드 P2의 VDD IO → 위쪽 빨간 줄 왼쪽 구간
  2. 보드 P2의 GND → 위쪽 파란 줄 왼쪽 구간
  3. 위 빨강 왼쪽 ↔ 오른쪽 / 위 파랑 왼쪽 ↔ 오른쪽
  4. 아래 빨강 왼쪽 ↔ 오른쪽 / 아래 파랑 왼쪽 ↔ 오른쪽
  5. 위 빨강 ↔ 아래 빨강 / 위 파랑 ↔ 아래 파랑

중앙을 잇는 4개 + 위아래를 잇는 2개, 총 6개의 전원 줄 연결선이 있습니다. 전원 줄을 잇는 선도 각각 별도 구멍에 꽂습니다.

보드 핀을 찾는 방향

USB 단자가 위로 오게 놓습니다. P2는 PORT1 00–15, 그 왼쪽 P3는 PORT1 16–31입니다.

  • P2 맨 위 왼쪽 VDD IO / 오른쪽 GND
  • P1.03: P2 오른쪽 03
  • P1.04: P2 왼쪽 04
  • P1.05: P2 오른쪽 05
  • P1.06: P2 왼쪽 06
  • P1.10: P2 왼쪽 10
  • P1.29: P3 오른쪽 29

별도 5V0 헤더는 사용하지 않습니다.

밥솥까지 선을 빼는 방법

광센서 4개는 잠금 표시, 보온 표시, 백미 표시, 시간 표시 맨 왼쪽에 각각 부착합니다. 센서마다 두 가닥을 이 표의 센서 구멍까지 연장합니다. 저항 11개는 브레드보드에 남습니다.

NTC는 외부 표면의 반복 측정 가능한 위치, 개폐센서는 뚜껑·본체에 나누어 부착합니다. 전선이 나온 접점 부품을 본체에 두면 움직이는 전선을 줄일 수 있습니다. 증기구·압력 장치·뚜껑 패킹을 피하고 뚜껑을 완전히 열 때도 당겨지지 않게 배치하세요. 길이는 설치 경로를 끈으로 재서 결정합니다.

현재 배치의 역할: 전면 광센서 4개와 접점·온도 센서의 조립 초안. 온도값을 음식 온도로 해석하지 않으며, NO 접점만으로 단선은 구별할 수 없습니다.

Fritzing에서 편집

Bapsim_All_Sensors.fzz를 Fritzing에서 열고 브레드보드 뷰를 사용하세요. 센서·저항·보드·선은 개별 객체이고 내부 연결 정보가 들어 있습니다. 보드 부품은 사용자 정의 부품 파일로도 제공됩니다.

이 파일은 브레드보드 조립용입니다. PCB 제작용 풋프린트, 회로 시뮬레이션, 자동 보정은 제공하지 않습니다. 다른 뷰의 자동 배치를 제조용 설계로 사용하지 마세요.

근거: 프로젝트 A08 배선 사전설계, 사용자 보드 사진, Nordic PCA10184 0.7.0 공식 회로도·설계 파일. 전기 연결 그래프의 단락·채널 분리·저항 위치 검사는 validation.json에 있습니다.
