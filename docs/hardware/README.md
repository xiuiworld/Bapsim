# 하드웨어와 관측 범위

| 구성 | 사용 부품 |
|---|---|
| 밥솥 | CUCKOO CRP-G1020MP |
| 보드 | nRF54LM20-DK, PCA10184 |
| Thread 보더 라우터 | Nest Hub 2세대 |
| 개폐 | NO 자석 접점 |
| 광센서 | GL5528 4개: 잠금·보온·백미·첫 시간 표시 위치 |
| 온도 | NTC 10kΩ B3950, 설치 지점의 표면 온도 |

[전체 배선도](wiring/README.md)와 [회로·핀 설계](A08_센서_배선_사전설계.md)를 참고한다. 외부 센서 관측이며 밥솥 내부 제어 회로나 제조사 API를 사용하지 않는다.

상단 첫 시간 LED는 예약/찜 표시 위치를 공유한다. 하나의 불빛으로 전체 예약 여부나 남은 시간을 확정하지 않는다. 주변광·인접 표시등 간섭 때문에 로컬 +16 후보는 해당 채널을 판단 불가로 제외한다. 설치 위치와 조명에 따라 광량이 달라지며 보정값을 다른 기기에 그대로 적용하지 않는다.

NO 접점의 단선은 정상 열림과 구별되지 않을 수 있다. NTC는 밥의 중심 온도가 아니며 기준 온도계에 대한 절대 정확도는 검증하지 않았다. 다른 모델의 설명서는 이 기기의 공식 사용설명서로 취급하지 않는다. 제조사 설명서 원본과 개인 설치 사진은 공개 묶음에 포함하지 않는다.

실물 검증 범위와 펌웨어 후보/설치 구분은 [검증 요약](../IMPLEMENTATION_STATUS.md)을 따른다.
