# 확정 하드웨어

- 제조사: **CUCKOO(쿠쿠)**
- 밥솥 모델: **CRP-G1020MP** — 2026-10-02 사용자 직접 확정.
- 구현 방식: 밥솥에 외부 센서를 부착해 관측하며 제조사 API는 사용하지 않습니다.

## 사용자 제공 설명서

로컬 참고 파일: `Cuckoo CRP-G1030MP Pressure Cooker.pdf` (GitHub 공유 대상에서 제외)

사용자가 제공한 32쪽 PDF를 프로젝트 루트에서 이 폴더로 옮겼습니다. 원본 내용과 파일명은 보존했습니다. 표지는 쿠쿠 10인분(1.8L) 마이콤 모델 사용설명서입니다.

**파일명은 CRP-G1030MP, 확정 기기는 CRP-G1020MP입니다.** 이 설명서가 확정 기기에 공통 적용되는지는 아직 확인하지 않았습니다. 확정 모델은 변경하지 않으며 LED 의미와 부착 위치 등은 실물과 대조합니다.

## 센서 사용 계획 — 2026-10-02 갱신

- GL5528 광센서: 구매 5개, 사용 계획 4개, 예비 1개.
- 부착 대상: 열림/잠김 LED, 보온 LED, 백미 LED, 상단 시간 표시부의 맨 왼쪽 LED.
- 추가 대상은 ‘예약 2시간 / 찜 10분’ 표기를 공유하는 LED다. 상단 6개 LED 전체를 읽는 구성이 아니다.
- 자석 개폐센서와 NTC 온도센서도 유지한다. 센서 구매 수량을 늘린 것은 아니다.
- 사용자가 첨부한 설명서 17쪽 화면에서 예약설정 시간은 ‘예약 취사 완료까지 남은 시간’이다. 예약 취소까지 남은 시간이 아니다.
- 광센서 하나로 전체 남은 시간·예약 여부를 확정하지 않는다. 점등·점멸 관측을 다른 신호와 함께 해석하고, 꺼짐도 예약 없음으로 단정하지 않는다.
- 구매 부품의 실제 부착·동작은 미검증이며, 핀·배선·회로는 상세 검토 대상이며 데이터 형식은 [Matter·HA 명세](../contracts/Matter_HA_연동_명세.md)와 [분석 입력 계약](../contracts/AB_데이터_계약.md)을 따른다.
