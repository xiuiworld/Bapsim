## 4 복원 절차

### 4.1 보드 앱 복원

현재 PC에서 저장소 루트를 연 PowerShell 기준이다. 먼저 `Get-FileHash <파일> -Algorithm SHA256`으로
위 표와 일치하는지 확인한다. 개발 보드는 `1051887912`, 앱 슬롯은 `[0xd000, 0x1f0000)`이다.
두 HEX는 이미 해당 슬롯 안의 앱 이미지로 검증했다. 공장 초기화나 전체 erase를 하지 않는다.

현재 A08 앱으로 되돌리는 명령:

```powershell
./tools/a07_edge/sdk_command.ps1 -CommandText 'west flash -d C:/Users/xiui/AppData/Local/Temp/baph1/history-v1 --no-rebuild --dev-id 1051887912 --hex-file C:/Users/xiui/Documents/Projects/Bapsim/local-data/deployments/2026-10-06-a08/product.signed.hex'
```

이전 버튼 시험 모드로 되돌릴 때는 마지막 파일명을 `rollback-manual.signed.hex`로 바꾼다.
이 경우 다시 합성 시험 온도·상태를 발행하는 수동 시험 앱이 된다는 점을 구분한다.
SDK는 `C:/ncs/v3.4.1`, 툴체인은 `C:/ncs/toolchains/4f5b6ad6dd`다.
임시 빌드 폴더가 없어졌다면 [A08 생성·빌드 안내](../../firmware/a08/README.md)대로 앱을 준비한 후
해당 앱 도메인 경로를 사용한다. 보관 HEX를 복원하는 데 모델을 다시 학습할 필요는 없다.

복원 후 HA 펌웨어 버전, ReportCounter 증가, `input_kind=test`, 미보정 신호 unknown,
기존 Matter node 재연결을 확인한다. A08에서는 UART의 `A08 INTEGRATION END failures=0`,
`A08 START ... driver_errors=0`, `A08 R`의 p/h=0, `A08 TIMING`도 확인한다.

### 4.2 현재 HA 수신기·B 코드 복원

기존 HA 설정을 백업한 다음 아래 범위만 교체한다. HA 구성 전체를 저장소 예제로 덮어쓰지 않는다.

1. `ha-sensor.py`를 기존 `/homeassistant/custom_components/bapsim_matter_probe/sensor.py`로 복사한다.
2. `bapsim-installed.zip`을 HA 설정 루트에 풀어 `custom_components/bapsim/`만 복원한다.
3. 기존 `configuration.yaml`의 A05 센서 항목에서 Matter entry/node가 2절과 같고
   `snapshot_history: true`인지 확인한다. B는 기존 `bapsim:` 내부 분석 모드를 유지한다.
4. 파일 해시/설치 내용 대조와 HA 구성 검사를 수행한 뒤 Core를 재시작한다.
5. 2절의 수신 상태, 최근 이력, B 시험 stopped와 live 대기 상태를 확인한다.
   등록된 휴대폰에 알림을 보내거나 live 생산자를 자동 등록하지 않는다.

현재 대기 상태 복원은 B의 `.storage`, 사용자 기록, 계약 JSONL을 지우는 작업이 아니다.
이 보관본은 코드 복구용이며 HA 전체 OS·사용자 데이터 복구 이미지는 아니다.

### 4.3 이전 HA 코드로 되돌릴 위치

| 이전 백업 | 의미 |
|---|---|
| `/homeassistant/a05-sensor-before-gap-fix.py.bak` | 읽기 오류 중 순번 유지 수정 전 A 수신기 |
| `/homeassistant/a05-history-before-20261005T141602Z.zip` | 이력 개선 설치 전 A/B 파일 및 configuration.yaml |

이 두 경로는 설치 당시 생성·검증 기록에 근거하며 이번에는 원격 파일 존재/해시를 재확인하지 않았다.
현재 상태 복원에는 4.2절의 로컬 보관본을 우선 사용한다. 이전 버전으로 돌아가면 이력 복원이나
누락 진단 개선이 사라질 수 있으므로 파일별로 섞어 되돌리지 않는다. HA 전체 복구는 HA의 전체 백업을 사용한다.

### 4.4 MQTT 재기동

기존 설정과 인증 데이터가 남아 있는 현재 PC 기준:

```powershell
docker compose --env-file deploy/haos/.env -f deploy/haos/compose.yaml up -d
docker compose --env-file deploy/haos/.env -f deploy/haos/compose.yaml ps
```

인증/데이터 위치는 `local-data/a06/mosquitto/`, 비밀이 포함된 실행 설정은 `deploy/haos/.env`다.
새 비밀번호 파일을 `-c`로 다시 만들어 덮어쓰지 않는다. 전체 설치 안내는
[기존 HA OS 실행 안내](../../deploy/haos/README.md)를 따른다.
