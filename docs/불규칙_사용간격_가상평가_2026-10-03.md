# 불규칙한 밥솥 사용 간격의 가상 평가

`python -m ai.irregular_interval_experiment`는 격일, 3일 간격, 2일·3일 교대 사용 가구를 만든다. 각 가구의 첫 28일을 모델에 관측시키고 뒤의 21일 동안 실제 서비스의 시간별 간격 판정과 알림 상태 관리를 재생한다. 사용 시각은 무작위로 흔들고, 자연스러운 건너뜀·미리 알린 외출·연결 단절과 두 번의 예정 사용 중단 사건을 넣었다. 가구와 난수 시드가 다른 개발·재현 집합을 사용했다. 모든 빈도와 사건은 **실측이 아닌 실험 가정**이다.

사건은 예정된 사용 2회를 연달아 놓친 기간이다. 그 사이의 사용 예정 없는 날에 알림 요청이 나와도 해당 사건의 첫 요청으로 계산한다. 실제 식사·안부 이상이나 휴대폰 도착을 확인한 결과는 아니다.

| 별도 재현 시드 4개, 12가구 | 현재 경험적 95% | 경험적 75% | 강건 예측 90% |
| --- | ---: | ---: | ---: |
| 중단 사건 첫 요청 | 11/24 | 15/24 | 16/24 |
| 정상일의 불필요한 요청 | 10/244 | 18/244 | 11/244 |
| 포착 사건의 중앙 요청 지연 | 24.27시간 | 20.27시간 | 41.71시간 |
| 포착 사건의 90% 요청 지연 | 37.93시간 | 32.93시간 | 65.10시간 |
| 미리 알린 외출·연결 단절일 요청 | 0 | 0 | 0 |

개발 시드에서는 기존 두 경험적 설정 모두 5/12사건을 포착했고 정상일 요청은 각각 5/120일, 10/120일이었다. 재현 집합의 3일 간격 가구에서는 경험적 75% 후보의 사건 포착이 4/8에서 3/8로 낮아졌다. 기준을 앞당기면 일부 사건을 더 빠르게 포착하지만 불필요한 보호자 확인 요청도 늘고 모든 리듬에서 개선되지 않는다. 따라서 운영 간격 분위수 95%를 유지했다.

## 작은 표본의 최장 간격 문제와 새 후보

기존 코드는 최근 유효 사용 간격을 정렬해 95% 위치의 관측값을 그대로 쓴다. 표본이 19개 이하일 때는 이 값이 **가장 긴 간격**이므로, 격일·3일 간격 가구에서 한 번의 긴 정상 공백이 다음 경고를 크게 늦출 수 있다. 이를 시험하기 위해 `robust_predictive` 후보를 추가했다. 로그 사용 간격의 중앙값과 중앙절대편차(MAD)로 다음 간격의 상한을 추정하고, 표본 수가 적을수록 범위를 넓힌다. 이는 반복 행동의 다음 시점을 모델링하는 [시간 사건 모델 연구](https://arxiv.org/abs/1802.09148)에서 문제 설정을 참고한 **가벼운 통계 후보**다. 해당 논문의 복잡한 모델을 구현했거나 성능을 재현한 것은 아니다. 표의 90%는 수학적 선택값이며 실생활 90% 보장이라는 뜻이 아니다.

개발 시드에서는 강건 예측 90%가 7/12사건을 포착하고 정상일 요청은 5/120일이었다. 재현 시드에서는 표처럼 포착이 11→16건으로 늘고 정상일 요청은 10→11일이었으나, **포착된 사건의 중앙 요청 지연이 약 17시간 길었다.** 두 설정이 포착한 사건 집합이 다르므로 동일 사건마다 17시간 늦어졌다는 뜻은 아니다. 95% 강건 예측은 12/24건·8/244일·중앙 44.37시간, 85%는 15/24건·11/244일·중앙 38.27시간이었다. 개발 결과를 보며 후보를 추가했으므로 재현 시드도 완전히 봉인된 최종 평가가 아니다.

자연스러운 사용 건너뜀 확률을 11%에서 30%로 올리고 별도 시드 2개를 쓴 추가 스트레스에서는 현재 설정이 5/12사건·정상일 6/118일, 강건 예측 90%가 7/12사건·9/118일이었다. 후자는 포착 사건의 중앙 지연이 27.25→22.95시간으로 줄었지만 90% 지연은 30.92→53.27시간으로 늘었다. 생성기의 나머지 구조는 같으므로 별개의 실제 분포를 검증한 결과는 아니다. 알림 지연과 보호자 부담을 함께 고려해 운영값은 바꾸지 않았다.

이 실험은 모델이 간헐적 밥솥 사용을 안전하게 판별한다고 입증하지 않는다. 알리지 않은 외출·외식과 실제 사용 중단이 같은 개방 기록을 만들면 식별할 근거가 부족하다. [전체 결과 JSON](../ai/irregular_interval_result.json)에 개발·재현 시드, 리듬별 포착, 지연, 놓친 사건 예시를 남겼다.
