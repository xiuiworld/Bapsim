# 불규칙한 밥솥 사용 간격의 가상 평가

`python -m ai.irregular_interval_experiment`는 격일, 3일 간격, 2일·3일 교대 사용 가구를 만든다. 각 가구의 첫 28일을 모델에 관측시키고 뒤의 21일 동안 실제 서비스의 시간별 간격 판정과 알림 상태 관리를 재생한다. 사용 시각은 무작위로 흔들고, 자연스러운 건너뜀·미리 알린 외출·연결 단절과 두 번의 예정 사용 중단 사건을 넣었다. 가구와 난수 시드가 다른 개발·재현 집합을 사용했다. 모든 빈도와 사건은 **실측이 아닌 실험 가정**이다.

사건은 예정된 사용 2회를 연달아 놓친 기간이다. 그 사이의 사용 예정 없는 날에 알림 요청이 나와도 해당 사건의 첫 요청으로 계산한다. 실제 식사·안부 이상이나 휴대폰 도착을 확인한 결과는 아니다.

| 별도 재현 시드 4개, 12가구 | 현재 95% 간격 | 75% 간격 후보 |
| --- | ---: | ---: |
| 중단 사건 첫 요청 | 11/24 | 15/24 |
| 정상일의 불필요한 요청 | 10/244 | 18/244 |
| 포착 사건의 중앙 요청 지연 | 24.27시간 | 20.27시간 |
| 미리 알린 외출·연결 단절일 요청 | 0 | 0 |

개발 시드에서는 두 설정 모두 5/12사건을 포착했고 정상일 요청은 각각 5/120일, 10/120일이었다. 재현 집합의 3일 간격 가구에서는 오히려 후보의 사건 포착이 4/8에서 3/8로 낮아졌다. 기준을 앞당기면 일부 사건을 더 빠르게 포착하지만 불필요한 보호자 확인 요청도 늘고 모든 리듬에서 개선되지 않는다. 따라서 운영 간격 분위수 95%를 유지했다.

이 실험은 모델이 간헐적 밥솥 사용을 안전하게 판별한다고 입증하지 않는다. 알리지 않은 외출·외식과 실제 사용 중단이 같은 개방 기록을 만들면 식별할 근거가 부족하다. [전체 결과 JSON](../ai/irregular_interval_result.json)에 개발·재현 시드, 리듬별 포착, 지연, 놓친 사건 예시를 남겼다.
