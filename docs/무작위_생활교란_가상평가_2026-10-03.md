# 무작위 생활 변화에 대한 가상 알림 평가

`python -m ai.benign_disruption_experiment`는 실제 밥솥 개방·알림 코드를 시간순으로 재생한다. 14일 이력을 쌓은 뒤 28일 동안 가상 1인 가구의 평소 사용(55%), 한 사용 시간의 외식(21%), 2.5시간 늦은 사용(11%), 미리 알린 외출(5%), 알리지 않은 외출(5%), 연결 단절(3%)을 날짜별 난수로 섞었다. 매일 한 번, 하루 두 번, 평일 점심은 외부에서 먹는 세 리듬과 독립 시드 8개를 조합했다. 비율은 **스트레스 시험을 위한 임의값**이며 한국 1인 가구의 측정 분포가 아니다.

알림 요청이 나온 날짜를 현재 날짜의 가상 상황으로 분류했다. 요청의 원인이 전날부터 이어진 미사용일 수 있으므로 표의 비율은 상황별 인과 효과가 아니다. 별도의 가상 집합에는 2일 연속 사용 중단을 두 번 넣어, 불필요한 요청을 줄이는 설정이 중단 포착도 줄이는지 확인했다. 뚜껑을 다시 열면 후보를 해제하는 실제 서비스 처리와 자정을 넘기는 평가 순서를 재현했다.

| 현재 설정, 정상 생활만 있는 24가구의 28일 | 날짜 수 | 첫 보호자 알림 요청이 나온 날짜 |
| --- | ---: | ---: |
| 평소 사용 | 392 | 0 |
| 외식으로 해당 사용 기회만 생략 | 140 | 18 |
| 늦은 사용 | 65 | 2 |
| 미리 알린 외출 | 25 | 0 |
| 알리지 않은 외출 | 33 | 17 |
| 연결 단절 | 17 | 0 |

정상 생활만 있는 집합에서 알림 요청은 총 37일이었다. 따라서 **현재 모델은 임의 외식·알리지 않은 외출을 위험한 사용 중단과 충분히 구별하지 못한다.** 미리 알린 외출과 단절은 이 실험에서 미사용으로 처리하지 않았다. 별도의 사용 중단 집합에서는 48사건 중 43건에 첫 요청이 나왔지만, 이 쉬운 합성 조건의 포착률을 현장 정확도로 해석할 수 없다.

같은 난수 기록에서 알림 기준 두 가지도 비교했다. 아래는 처음 실험에 쓰지 않은 시드 8개의 재현 결과다.

| 설정 | 정상 생활 중 요청 날짜/유효 630일 | 사용 중단 사건 포착/48건 | 포착 건 중앙 요청 지연 |
| --- | ---: | ---: | ---: |
| 현재: 2회 확인 | 37 | 43 | 13.05시간 |
| 사용 지연 1시간 추가 허용 | 34 | 43 | 14.14시간 |
| 3회 확인 | 10 | 30 | 25.98시간 |

1시간 유예는 이 가상 조건에서 불필요한 요청을 3일 줄이고 포착 사건 수는 같지만, 요청은 더 늦어진다. 3회 확인은 포착 손실이 크다. 이 결과만으로 운영 설정은 바꾸지 않았다. [전체 JSON](../ai/benign_disruption_result.json)에 개발·재현 시드와 리듬별 세부 결과를 남겼다.

센서가 보여주는 것은 밥솥 사용 여부다. **알리지 않은 외출·외식과 사용 중단이 동일한 관측 기록이면 모델은 둘을 확실히 구별할 수 없다.** 반복되는 외부 식사 요일은 초기 시간·요일 입력으로 반영하고, 예외적인 외출은 `bapsim.set_away`로 선언할 수 있다. 알림 문구는 위험 확정이 아닌 보호자 확인 요청으로 유지한다. 실사용·실기기·실제 휴대폰 도착은 이 평가에 포함되지 않았다.
