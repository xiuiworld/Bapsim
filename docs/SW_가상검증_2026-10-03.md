## 재현 명령

```powershell
python -m unittest discover -s tests -q
python -m tools.run_software_matrix
python -m tools.build_ha_bundle
python -m tools.check_local_ha
```

`run_software_matrix`는 `local-data/software-matrix-<UTC시각>.json`에 입력 유형, 실행 테스트, 결과, 합성 평가 지표와 제한을 저장한다. `local-data/`는 Git에서 제외한다. 실패한 시나리오가 있으면 명령이 실패 코드로 끝난다.

## 로컬 재시작 점검

- 독립 작업자 이미지를 다시 빌드해 재생성하고 HA를 재시작했다. Mosquitto와 함께 세 컨테이너가 실행 중이다.
- 새 작업자 이미지에서 재시도 간격 `30/120/300초`를 확인했다. 저장된 작업자 상태 JSON을 파싱해 복원 가능한 형식임을 확인했다.
- HA 로컬 API에서 `sensor.bapsim_notification_delivery`, `sensor.bapsim_observation_issue_status`, `sensor.bapsim_workflow_status`가 모두 HTTP 200으로 조회됐다. 현재 HA는 외부 작업자 모드이므로 세 센서 상태는 `external_worker`다.
- 실제 폰 서비스 호출이나 실제 Matter 입력은 이 점검에서 실행하지 않았다.
