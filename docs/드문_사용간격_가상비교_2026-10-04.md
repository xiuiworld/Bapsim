# 드문 사용 간격의 가상 알림 비교 (2026-10-04)

실측 데이터 없이 스크립트로 만든 밥솥 사용 중단을 평가했다. 결과는 식사 여부, 건강 상태, 실제 가구 성능의 추정치가 아니다. 재현 코드는 `ai/cadence_confirmation_experiment.py`, 원자료 요약은 `ai/cadence_confirmation_result.json`에 있다.

## 변경 기준

기존 간격 모델은 최근 관측된 사용 간격의 경험적 95% 값에 의존한다. 7~20개 정도의 간격에서는 긴 공백 하나가 기준을 크게 늦출 수 있다. 새 기본 전략 `sparse_guarded_predictive`는 간격 중앙값이 **36시간 이상**일 때만 로그 간격 중앙값과 MAD로 계산한 예측 90% 값과 경험적 95% 값 중 이른 쪽을 사용한다. 그보다 잦은 사용 패턴은 기존 경험적 95% 값을 그대로 사용한다. 시계 시간대별 예상 구간이 충분히 뚜렷하면 기존처럼 간격 모델 자체를 사용하지 않는다.

## 비교 방법

- 개발 집단: 새 시드 2381·2399, 안정·자연스러운 건너뜀·3일 주기 조건, 시간 변동 또는 개방 보고 누락 변형. 48가구, 사건 96회.
- 별도 검증 집단: 새 시드 4903·4931, 점진적 시각 이동·주말 이동·건너뜀과 지각 조건, 추가 시각 이동·건너뜀 변형. 24가구, 사건 48회.
- 두 집단 모두 21일 학습 뒤 21일을 시간순으로 재생했다. 하루 사용, 하루 두 번 사용, 이틀 주기 사용 등 4가지 합성 생활형을 사용했다. 각 사건은 예정된 사용 두 번이 중단되는 스크립트다.
- 개발 집단에서 정상일의 불필요한 알림 요청이 기존 이하인 후보 중 사건 포착 수가 가장 큰 후보를 골랐다. 검증 집단은 선택 후 한 번 평가했다. 결과는 기존 연구에서 반복 확인한 보류 집단과 별개다.

| 집단 | 전략 | 사건 포착 | 정상일 불필요 요청 | 첫 요청 지연 중앙값 | 첫 요청 지연 90백분위 |
| --- | --- | ---: | ---: | ---: | ---: |
| 개발 | 기존 경험적 95% | 38/96 | 20/720일 | 25.89시간 | 26.11시간 |
| 개발 | 드문 사용 보호 기준 | 43/96 | 16/720일 | 25.94시간 | 54.98시간 |
| 검증 | 기존 경험적 95% | 21/48 | 19/360일 | 24.88시간 | 26.10시간 |
| 검증 | 드문 사용 보호 기준 | 24/48 | 16/360일 | 25.16시간 | 53.38시간 |

개발 집단에서 53/96건, 검증 집단에서 24/48건은 새 기준으로도 놓쳤다. 90백분위 지연은 증가했다. 기존에 아예 놓쳤던 늦은 사건을 추가로 포착한 영향도 포함되므로, 이 결과를 알림이 더 빨라졌다는 뜻으로 해석하면 안 된다. 검증 집단의 개선은 이틀 주기 합성 생활형에 집중되어 있으며 다른 생활형은 이 비교에서 변하지 않았다.

실측이 생기면 개방 누락률, 외출·연결 단절, 실제 보호자 확인 결과를 분리하여 다시 검증해야 한다. 현재 합성 생성기는 정답과 생활형을 사람이 정했으므로 실제 생활의 다양한 원인을 대표하지 못한다.
