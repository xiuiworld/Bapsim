# 실사용 데이터 없는 강건성 실험 — 2026-10-03

## 차용한 방법

- [Domain randomization (Tobin 등, 2017)](https://arxiv.org/abs/1703.06907)은 시뮬레이션의 조건을 다양하게 바꾸어 한 생성 조건에 맞춰지는 문제를 줄인다. 원 논문은 로봇 영상에 적용했다. 여기서는 **아이디어만 차용**해 자연스러운 미사용률, 사용 시각 흔들림·이동, 개방 신호 누락을 가상 가구마다 바꾼다. 이 적용이 실제 밥솥 사용으로 전이된다는 증거는 아니다.
- [Group DRO (Sagawa 등, 2020)](https://arxiv.org/abs/1911.08731)는 미리 정한 집단 중 가장 나쁜 손실을 줄이는 학습을 연구한다. 여기서는 신경망 학습이 아니라 **후보 설정 선택에만** `생활 리듬 × 교란 유형`별 최대 손실을 사용했다. 손실은 `1 − 중단일 당일 발송 요청 포착률 + 2 × 정상일 발송 요청률`이다. 이 목적함수와 2배 가중치는 밥심 실험 가정이다.
- [시계열 순차 검증 (Hyndman·Athanasopoulos)](https://otexts.com/fpp3/tscv.html)의 미래 정보 누출 방지 원칙에 맞춰 각 가구의 과거 21일을 먼저 입력하고 다음 21일을 날짜 순서대로 평가했다. 가구·난수 시드·조건이 다른 보류 집합을 선택에 쓰지 않았다.

## 실행과 결과

`python -m ai.robust_notification_experiment`로 재현한다. 훈련에는 기존 생활과 별도로 시각/건너뜀 변화, 개방 신호 8% 누락을 넣었다. 보류 집합에는 두 변화를 **동시에** 넣고 다른 가구 시드와 조건을 사용했다. 4개 알림 후보를 비교해 훈련의 최악 집단 손실이 가장 낮은 `single_high_confidence`를 선택했다.

| 설정 | 훈련 최악 집단 손실 ↓ | 훈련 포착 / 정상일 요청 | 보류 복합 조건 포착 / 정상일 요청 |
|---|---:|---:|---:|
| 현재 운영 설정 | 1.1334 | 25.0% / 4.4% | 13/64 (20.3%) / 12/240 (5.0%) |
| 강건 선택 후보 | 1.1041 | 24.0% / 8.1% | 9/64 (14.1%) / 16/240 (6.7%) |

훈련의 최악 집단 숫자는 조금 좋아졌지만 **보류 복합 조건에서는 포착이 낮고 정상일 요청은 많았다.** 따라서 이 후보를 운영 모델에 적용하지 않았다. 기존 모델·알림 기준을 유지한다. 특히 격일 사용 가구는 두 설정 모두 보류 중단일 16건 중 당일 요청 0건이었다. 사건 단위로 보면 현재 설정은 32건 중 13건을 포착했고 포착 건의 중앙 알림 요청 지연은 24.32시간이었다. 두 지표 모두 실제 보호자 도착을 뜻하지 않는다.

훈련·보류 시나리오는 모두 같은 프로그램으로 설계한 **가상 가정**이다. 보류 성능도 현장 성능 추정치가 아니다. 센서 누락 확률 역시 측정값이 아니라 스트레스 값이며, 놓친 개방과 실제 미사용은 센서만으로 구분되지 않을 수 있다. 이 실험의 성과는 새 모델이 더 정확하다는 결론이 아니라, 평균 성능만 보고 운영값을 바꾸면 취약한 생활 유형에서 악화될 수 있음을 재현한 것이다. 실행 결과 전체는 [JSON](../ai/robust_notification_result.json)에 남긴다.
